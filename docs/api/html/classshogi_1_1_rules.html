Detailed Description

Pure functions over a Board — no game history.

Pseudo-legal generators ignore own-king safety; generate_legal filters check, nifu and uchifuzume.

bool shogi::Rules::both_kings_entered ( Board const & board)
static

Jishogi (impasse) helpers — Tokyo / hobby manual style.

Rook & Bishop = 5 (ignore promotion); King = 0; all other pieces = 1 (board + hand). Threshold 24. Ending is via Game::claim_jishogi.

Returns
True if both kings sit in their own promotion zones (entered).
