Detailed Description

Piece-set chooser and game options.

Clock / handicap toggles; New game / Engine may open a setup dialog first. Setup keyboard: ↑/↓ by row; ←/→ within Sente|Gote and Start|Cancel; Enter/Space confirms (uwate like piece-set selection); Esc closes.
